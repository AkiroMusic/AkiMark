Features

What it does

AkiMark is a minimal, always-resident screen markup utility built with Tauri v2 + Vue 3. It sits quietly in the system tray at near-zero resource cost and brings up a full-screen drawing overlay in milliseconds on a global hotkey — great for presentations, screen recordings, teaching and live collaboration. Currently a beta preview (v0.2.6).

⚡

Instant activation

A pre-built hidden overlay window appears in milliseconds on a single global hotkey. The app stays resident in the tray with near-zero footprint; click-through keeps your annotations visible while you keep working.

🖌️

Eleven tools

Pen, highlighter, eraser, line, rectangle, circle, arrow, text, fading pen, blur and step counter — with an 8-color palette cycled via Q/E.

🔍

Buttery-smooth strokes

Dual-canvas engine with quadratic Bézier midpoint smoothing and coalesced pointer events. Pressure-sensitive on pen tablets; mouse and trackpad draw at a constant width.

⏳

Fading pen & mosaic

Fading strokes dissolve about 3 s after being drawn; the blur pen pixelates the underlying screen along the stroke path.

🔦

Spotlight & zoom

Dim everything except a follow-cursor highlight, or freeze-zoom the whole overlay 2x–8x anchored on the cursor — and keep drawing while zoomed.

🧑‍🏫

Whiteboard / blackboard

Flip the overlay into a plain board for free-hand lecturing; exports skip the screen capture.

📸

Export & copy

Composite annotations onto the underlying screen, save as PNG to a custom folder or copy to the clipboard. Full undo / redo / clear history stack.

🚦

No dead states

Overlay modes are mutually self-consistent: Esc steps out layer by layer (zoom → spotlight → board → exit), hotkey conflicts are detected inline, and a single-instance guard keeps the tray clean.

Quick Start

Build from source

  1. Install Node.js ≥ 20, Rust (stable, 1.77+) and the Tauri v2 prerequisites — WebView2 on Windows.
  2. Run npm install, then npm run dev.
  3. The app starts resident in the tray and opens the settings window.
  4. Press Ctrl+Shift+R to start annotating.
shell
npm install
npm run dev

npm run build      # bundles installer (NSIS) into src-tauri/target/release/
npm run build:fe   # frontend only (vue-tsc + vite)

项目简介

AkiMark 是一款基于 Tauri v2 + Vue 3 构建的极简常驻屏幕标注工具。它安静地驻留在系统托盘中，资源占用近乎为零；按下全局热键即可在毫秒级唤起全屏绘制覆盖层——非常适合演示、录屏、教学与实时协作。当前为内测预览版（v0.2.6）。

⚡

即时激活

预建的隐藏覆盖窗口，按一次全局热键即可毫秒级显示。应用常驻托盘、占用近乎为零；穿透模式让你在继续操作的同时保持标注可见。

🖌️

11 种工具

画笔、荧光笔、橡皮、直线、矩形、圆形、箭头、文字、渐隐笔、马赛克笔、序号标注——配 8 色调色板，Q/E 快速循环切换。

🔍

顺滑的笔迹

双画布引擎，二次贝塞尔中点平滑与合并指针事件。数位板笔支持真实压感；鼠标与触控板以恒定宽度绘制。

⏳

渐隐笔与马赛克

渐隐笔画在绘制约 3 秒后自动溶解；马赛克笔沿笔画路径将底层屏幕画面打上马赛克。

🔦

聚光灯与缩放

压暗四周、突出跟随光标的亮点，或以光标为锚点将整个覆盖层冻结放大 2x–8x——放大状态下仍可继续绘制。

🧑‍🏫

白板 / 黑板

一键切换为纯色板书底，自由板书；导出时跳过屏幕截取。

📸

导出与复制

将标注合成到底层屏幕，保存为 PNG 到自定义目录，或一键复制到剪贴板。完整的撤销 / 重做 / 清屏历史栈。

🚦

无死状态

覆盖层各模式互斥关系完全自洽：Esc 逐级退出（缩放 → 聚光灯 → 板书 → 退出标注），热键冲突内联检测，单实例保护让托盘始终清爽。
